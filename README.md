# URL Shortener — система сокращения URL-адресов

## 1. Описание проекта

URL Shortener — приложение для создания и управления сокращёнными URL-адресами, разработанное на языке программирования Clojure.

Приложение состоит из двух основных частей:

- **REST API-сервер** — обрабатывает HTTP-запросы и управляет данными.
- **Консольный клиент** — предоставляет пользователю интерактивное меню для работы с URL-адресами.

Для постоянного хранения данных используется база данных SQLite.

## 2. Используемые технологии

- Clojure 1.12.2 — язык программирования.
- Java 21 — платформа выполнения приложения.
- Leiningen — управление зависимостями и сборка проекта.
- Ring и Jetty — HTTP-сервер.
- Cheshire — обработка JSON.
- next.jdbc — взаимодействие с базой данных.
- SQLite — хранение URL-адресов.

## 3. Функциональные возможности

Приложение позволяет:

1. Создавать сокращённые ссылки с уникальными шестисимвольными кодами.
2. Получать исходный URL по короткому коду.
3. Изменять исходный URL существующей записи.
4. Удалять сокращённые ссылки.
5. Проверять корректность введённых URL-адресов.
6. Обрабатывать ошибки и запросы к несуществующим записям.
7. Сохранять данные между перезапусками сервера.

## 4. Структура проекта

Основные файлы исходного кода:

- `core.clj` — главная точка входа и выбор режима запуска.
- `client.clj` — консольный клиент.
- `server.clj` — обработка REST API и запуск HTTP-сервера.
- `service.clj` — бизнес-логика приложения.
- `validation.clj` — проверка корректности URL и коротких кодов.
- `db.clj` — работа с SQLite.

Исходный код расположен в `src/url_shortener/`.

Автоматические тесты находятся в `test/url_shortener/`.

## 5. Требования для запуска

Для сборки приложения необходимы:

- Java 21;
- Leiningen;
- операционная система Windows, Linux или macOS с установленной Java.

Для запуска готового JAR-файла Leiningen не требуется.

## 6. Сборка приложения

Откройте PowerShell в каталоге проекта:

`C:\Projects\url-shortener`

Выполните команду:

`lein uberjar`

После успешной сборки будет создан файл:

`target/uberjar/url-shortener-0.1.0-SNAPSHOT-standalone.jar`

Он содержит приложение и необходимые зависимости.

## 7. Запуск REST API-сервера

Выполните команду:

`java -jar target/uberjar/url-shortener-0.1.0-SNAPSHOT-standalone.jar 8080`

Сервер запустится на порту 8080.

Адрес API:

`http://localhost:8080/api/urls`

При первом запуске автоматически создаётся база данных `urls.db`, если она ещё не существует.

## 8. Запуск консольного клиента

Оставьте сервер работающим.

Откройте второе окно PowerShell и выполните:

`java -jar target/uberjar/url-shortener-0.1.0-SNAPSHOT-standalone.jar`

На экране появится меню:

1. Create short URL — создать сокращённую ссылку.
2. Get original URL — получить исходный адрес.
3. Update URL — изменить ссылку.
4. Delete URL — удалить ссылку.
5. Exit — завершить работу.

Клиент отправляет HTTP-запросы на сервер по адресу `http://localhost:8080`.

## 9. Описание REST API

### 9.1. Создание сокращённой ссылки

**Метод:** `POST`

**Адрес:** `/api/urls`

Тело запроса:

`{"original_url":"https://example.com"}`

При успешном создании сервер возвращает HTTP 201 и JSON с коротким кодом:

`{"short_code":"aB3xY9"}`

Код генерируется случайным образом.

### 9.2. Получение исходного адреса

**Метод:** `GET`

**Адрес:** `/api/urls/{code}`

Пример:

`GET /api/urls/aB3xY9`

Ответ HTTP 200:

`{"original_url":"https://example.com"}`

### 9.3. Изменение адреса

**Метод:** `PUT`

**Адрес:** `/api/urls/{code}`

Тело запроса:

`{"original_url":"https://www.wikipedia.org"}`

При успешном изменении сервер возвращает HTTP 200:

`{"message":"OK"}`

### 9.4. Удаление ссылки

**Метод:** `DELETE`

**Адрес:** `/api/urls/{code}`

При успешном удалении сервер возвращает HTTP 200:

`{"message":"OK"}`

Повторный запрос к удалённому коду возвращает HTTP 404.

## 10. Обработка ошибок

Приложение использует следующие HTTP-коды:

| Код | Описание |
|---|---|
| 200 | Операция выполнена успешно |
| 201 | Сокращённая ссылка создана |
| 400 | Некорректный URL или тело запроса |
| 404 | Запись или API-маршрут не найдены |
| 503 | Не удалось сгенерировать уникальный код |

## 11. Хранение данных

В качестве системы хранения используется SQLite.

Таблица `urls` содержит следующие поля:

| Поле | Назначение |
|---|---|
| `id` | Уникальный идентификатор записи |
| `short_code` | Уникальный короткий код |
| `original_url` | Исходный URL-адрес |
| `created_at` | Дата и время создания |

Файл `urls.db` создаётся в рабочем каталоге сервера.
